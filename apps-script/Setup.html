ยังตั้งค่าระบบไม่ครบ

ทำตามขั้นตอนต่อไปนี้ในตัวแก้ไข Apps Script แล้วรีเฟรชหน้านี้อีกครั้ง

  1. เปิดไฟล์ Code.gs แก้ค่าในฟังก์ชัน initProject() ให้เป็น Channel ID และ Channel Secret ของ LINE Login channel ของตนเอง
  2. กด Run ฟังก์ชัน initProject() หนึ่งครั้ง ระบบจะสร้าง Google Sheet พร้อมทุกตารางและข้อมูลตั้งต้นให้อัตโนมัติ
  3. เปิด Deploy > New deployment เลือก Web app ตั้ง Execute as = Me และ Who has access = Anyone แล้วคัดลอก URL ที่ลงท้ายด้วย /exec
  4. นำ URL นั้นไปใส่ในช่อง Callback URL ของ LINE Login channel ที่ LINE Developers Console
  5. รันฟังก์ชัน showConfig() เพื่อตรวจสอบค่าที่ตั้งไว้

Callback URL ที่ต้องใส่ใน LINE Developers
